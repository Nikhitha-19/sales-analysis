# 📊 Super Store Sales Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Super Store Sales Dashboard** developed using **Microsoft Power BI**. The dashboard provides comprehensive insights into sales performance, profit, product categories, customer segments, shipping methods, and regional trends.

It enables users to analyze business performance through interactive visualizations and key performance indicators (KPIs), supporting data-driven decision-making.

---

## 🎯 Objectives

- Analyze overall sales, profit, and quantity sold.
- Monitor monthly sales and profit trends.
- Compare sales across product categories and sub-categories.
- Analyze customer segments and shipping methods.
- Visualize sales and profit distribution across different states.
- Provide interactive filters for regional analysis.

---

## 📂 Dataset

The dashboard is built using a Super Store Sales dataset containing the following fields:

- Row ID

- Order Date
- Ship Date
- Ship Mode

- Customer Name
- Segment
- Country
- City
- State
- Region
- Product ID
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Profit
